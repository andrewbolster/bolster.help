Questions about Northern Ireland, answered from official statistics.

Point it at a model

The key is sent from this browser straight to that endpoint, and is kept until you close the tab. The endpoint has to allow cross-origin requests.

    Data comes from NISRA, PSNI, DfI and Companies House via mcp.bolster.online. Figures are as published; a small model can still misread them. The tools are a Python package — bolster.readthedocs.io.
