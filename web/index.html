bolster.help

Questions about Northern Ireland, answered from official statistics. The model runs on your own machine — what you type never reaches a server.

This browser can't run the model

Inference here needs WebGPU, which this browser doesn't expose. Chrome or Edge on a desktop will work. Nothing has been downloaded.

The underlying data tools are a Python package — bolster.readthedocs.io documents them.

Load the model

First run downloads about 4.5 GB of model weights and caches them in this browser. Later visits start immediately.

    Data comes from NISRA, PSNI, DfI and Companies House via mcp.bolster.online. Figures are as published; a small model can still misread them.
